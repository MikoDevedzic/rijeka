INDEPENDENT CONFIRMATION VERIFIER

Checks a bilateral trade confirmation without trusting the system that produced it. Everything runs in your browser: the hash is recomputed from the trade terms, both signatures are recovered locally, and the registry is read straight from a public Ethereum node. No Rijeka server is contacted at any point.

Open source, MIT. The registry contract source is verified on Sourcify — read it before you trust this page. This file is self-contained: save it and it keeps working.
Canonical form: JSON, keys sorted at every level, separators , and :, no whitespace, UTF-8, then keccak256.
